おうちの方へ

正式なチェスのルール（キャスリング・アンパッサン・プロモーション・引き分け判定）に対応した、子ども向けの3Dチェスです。画面の文字はすべてひらがなです。

ブラウザで遊ぶ

「いますぐ あそぶ」を押すだけで、スマホ・タブレット・パソコンのブラウザで遊べます。インストールは不要です。

Android アプリとして入れる

  1. 「アプリを ダウンロード」から 3Dchess.apk をダウンロードします。
  2. ダウンロードしたファイルを開きます。
  3. 「提供元不明のアプリ」の許可を求められたら、ブラウザ（またはファイルアプリ）に許可を出します。
  4. 「インストール」を押すと、ホーム画面に「3Dちぇす」が追加されます。

対応：Android 8.0 以降。Google Play 以外からのインストールになるため、上の許可が必要です。

安心して使えるように

  • 広告・課金はありません。
  • アプリはインターネット接続の権限を持たず、データを外部に送りません。
  • 途中の対局は端末の中にだけ保存されます。
